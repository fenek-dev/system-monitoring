# On-screen Stats Overlay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A click-through overlay shows CPU, GPU and memory, each with its 60-s min/max/avg. A global hotkey (default ⌥Z) toggles it. While it is on, a light 1-s "overlay" sampling mode runs.

**Architecture:**
- **Engine:** a new `SamplingMode.overlay`. Totals sensors tick every 1 s; everything else runs at 5 s. History records only on 5-s ticks, with a 5-s interval.
- **LiveModel:** gains an `.overlay` presentation level that publishes only cpu, gpu, memory and the series.
- **Screens:** a pure SwiftUI `OverlayView`, plus pure helpers: stats, placement, display choice.
- **App:** a Carbon hotkey and a click-through `NSPanel`.

**Tech Stack:** Swift 6.3 (strict concurrency), SwiftUI + AppKit, Carbon `RegisterEventHotKey`, Swift Testing, snapshot harness (`MonitorSnapshotTesting`).

**Spec:** `docs/superpowers/specs/2026-09-25-overlay-design.md`. Code facts are in `.superpowers/sdd/overlay-codemap.md`: read the sections your task names.

## Global Constraints
- macOS 14+, arm64. No `@unchecked` outside MonitorMocks, no `&-` outside RateCalculator.swift, no `map(Double.init)`. `scripts/ci.sh` enforces all three.
- Edit files with the Edit or Write tool, never sed, python or heredoc.
- Rerun only the tests you touched. At the end of each task, run `scripts/ci.sh <your suites>` once. Snapshot tests run strict (`TT_SNAPSHOT_STRICT=1`); record new goldens with `TELLTALE_RECORD=1`, then check each one by eye.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Metric names: `.cpuUsage` and `.gpuUsage` are fractions 0…1, formatted with `TTFormat.percent(_:)`. `.memUsed` is in bytes.
- Overlay copy: labels "CPU", "GPU", "MEM"; stats row "↓{min} ↑{max} ø{avg}"; unavailable "—".

## Rulings (deviations from the spec, decided while planning)
- **R1.** When `SensorCadence.overlay` is nil, the overlay interval is `max(background, 5 s)`: every-tick sensors run at 5 s in overlay mode, not 1 s. A nil `background` means never.
- **R2.** A sensor is due when `now + tick/2 ≥ lastAttempt + interval`, applied in every mode. This half-tick slack stops a 5-s sensor on a 1-s grid from slipping to 6 s.
- **R3.** Overlay records: a record is emitted only when the process table slot was fresh on that tick, and its `interval` is 5 s. Events are always emitted.
- **R4.** LiveModel `presentation: LivePresentation` (`.none`, `.overlay`, `.full`) replaces the bare `isPresenting` in the app wiring. `isPresenting` stays as a computed alias (`== .full`) so existing code keeps compiling.
- **R5.** Opacity is a `TTSegmented` with 4 steps (55/70/85/100 %), not a slider, because the kit has no slider. Default 85.
- **R6.** The memory stats row uses a new `TTFormat.memoryNumber(_:)`: the same divisor and digits as `memory(.headline)`, without the unit.
