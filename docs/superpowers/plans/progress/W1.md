- `StorageTreeBuilder.init(root:dev:volumeUUID:rootFileID: = 0, rootMtime: = 0)`: root node identity/mtime.
- Hard links (r1 redesign): `HardLinkGroup { identity, linkCount = max st_nlink seen (all filesystem links incl. outside the scan), allocBytes, privateBytes?, provenance, occurrences: [LinkOccurrence {node, depth, isFolded}] }`, occurrences sorted by (depth, path); folded = dir node, depth = dir depth + 1. Scanner contract: link files pass `NodeRecord.allocBytes == 0`; folded ones count in `addSmall` `count` but not bytes; bytes only via `addLink(_:linkCount:bytes:occurrence:privateBytes: = nil)`. Map credit at `occurrences[0]`.
- Restricted node: zeroed after its descendants rolled into it, before adding to its parent.
- `StorageTree`: public memberwise init (all arrays + `version: = StorageTree.nextVersion()`) for ScanCache; `static nextVersion()`; extra helpers `nodeCount`, `nameBytes(_:)`, `identity(_:)`. `isAncestor` is proper (node is not its own ancestor). `lookup(path:)` exact bytes per component; root path → 0. `remainderBytes` excludes the node's folded `smallBytes`. `childPrefix` = inclusive running sums.
- `StorageTreeOverlay` (r2 declarative redesign): same entry points — `init(tree:)`, `remove(_:kind: .deleted|.trashed, in:)`, `shrink(_:by:in:)`, `restore(_:originalNode:in:)`, `rebased(onto:) throws` (checks `ScanIdentity`: root, volume UUID, scan date, node count), `size`/`isRemoved` throwing `.treeMismatch` (other tree version, or decoded and not yet rebased), `restoredEntries(under:)`, `deletedLinkCount(group:)`, `linkSurvives(group:occurrence:)`. New: `name(_:in:)` (display name after a renamed undo), `Location {live, trashed(snapshot:), deleted}`. State = where each node's content physically is: `original[node]` (absent = live), `recreated[node]: Set<Location>` (empty dirs made by undo), `renamed`/`renamedRecreated`, node-less `restored` entries + `restoredLocations`, `trashRoots`, `shrunk` (UInt128). Removed incremental fields (`removed`, `revived`, `sizeDelta`, `linkHolder`, `goneLinks`). Remove moves everything live in the subtree into one new Trash snapshot or deleted; undo of a node brings back its latest snapshot (renamed if `entry.name` differs; `entry.bytes` ignored for node restores) and recreates hidden ancestors as empty dirs. Sizes, visibility, hard-link credit (first occurrence by depth/path whose original instance is live) and deleted-link counts come from one O(nodes) recompute per mutation, cached in the struct (not encoded). Keep-parent `shrink` doesn't mark folded links gone. Known limit: if a node's original and a recreated instance are both live (renamed undo next to a recreated dir), they show merged as one node.
- `ReclaimAccumulator` (r1): `init(items:tree:overlay: = nil, linkSizes: = [:]) throws(StorageOverlayError)`; group counts iff surviving occurrences inside the union == `linkCount − deleted links` (trashed links still required); group bytes = private if `.exact`, else `allocBytes` with provenance ≥ `.estimate`; `provenance` includes counted groups; totals `UInt128`, `bytes` clamps. + `selectedIDs`, `count`. Items with `privateBytesExcludingLinks == nil` contribute `allocBytes` and don't take part in link coverage.
