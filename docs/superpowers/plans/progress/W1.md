- Hard-link contract: link files (linkCount > 1) pass `NodeRecord.allocBytes == 0` and are left out of `addSmall` bytes; bytes go only through `addLink`; `finalize` credits once at the lowest-depth occurrence (ties: path bytes), into the file node's size, or into the dir's `smallBytes` when the occurrence is a dir.
- `StorageTree`: public memberwise init (all arrays + `version: = StorageTree.nextVersion()`) for ScanCache; `static nextVersion()`; extra helpers `nodeCount`, `nameBytes(_:)`, `identity(_:)`. `isAncestor` is proper (node is not its own ancestor). `lookup(path:)` exact bytes per component; root path → 0. `remainderBytes` excludes the node's folded `smallBytes`. `childPrefix` = inclusive running sums.
- `StorageTreeOverlay`: `treeVersion` is `private(set) var`; `rebased(onto:)` rebinds a sidecar to a cache-reloaded tree (process-local versions differ); `isEmpty`, `restoredEntries(under:)`; `RestoredEntry` is a public struct. Restore to original = same parent + same name + node in `removed`.
- `ReclaimAccumulator`: + `selectedIDs`, `count`. Items with `privateBytesExcludingLinks == nil` contribute `allocBytes` and don't take part in link coverage.
- `StoragePolicy`: data = `treeVersion: UInt64?`, `anchors`, `protected: Set<StorageNodeID>`; version mismatch → `.unverifiable`; `.none` allows all.
- `ClassifyOptions` init defaults: large 500 MB, old 50 MB, oldAge 183 d (`defaultLargeBytes` etc. statics).
