## Design decisions (fixed)

- **Layout** (DESIGN §3.0/§3.17): content padding 20, VStack gap 12, `grid3`. Order: FDA banner (if `hasFullDiskAccess == false` and not dismissed this session — page `@State`, not persisted) · stat strip · mode switch row · mode content (flex). **Compact** = page width < 1000 pt (1100 window → 880; 1280 → 1060), measured once with `GeometryReader` in `StoragePage` and passed down as `compact: Bool` (`StorageChrome` holds the threshold constant with a why-comment); compact drops Purgeable from the strip and the Items column from the children table.
- **Header trailing** (`StorageHeaderControls`, self-observing): root chip (`TTButtonStyle(.chip)`-like single button "~ ▾" → `Menu`: Home / Choose Folder… (`NSOpenPanel` directories only → `selectRoot(.folder(path))`) / `availableRoots` volumes; disabled while `busyReason == .cleaning`) · `Scanned …` (`StorageFormat.scannedAgo(summary or final tree scanDate, now: \.now ?? Date())` — **only** when a final tree/summary exists, never from a partial tree (live partial trees stamp `Date()`); refresh with `TimelineView(.everyMinute)` only when `!isSnapshot`) · `Scan` (`.smallPrimary`, no result yet) / `Rescan` (`.smallSecondary`) / `Cancel` (`.smallSecondary`, while `.scanning`); Scan disabled when `!canScan` with tooltip "Cleaning in progress". Subtitle: `root.path` with home abbreviated to `~`.
- **Stat strip** (`TTStatStrip`, §5.3 headline): Capacity · Used · Free · Purgeable · Reclaimable · Trash. Capacity/Used/Free/Purgeable from `live.disk.bootVolume` for `.home` and the Data volume; for other roots "—" with `unavailableReason` "Not reported for this volume" (no new sensor work). Reclaimable = `summary.reclaimableBytes` via `StorageFormat.bytes` ("—" before the first home scan); Trash = `cleanup` trash total / `summary.trashBytes`: `Empty` at 0, "—" when unknown.
- **Mode switch**: `TTSegmented([.spaceMap: "Space Map", .cleanup: "Cleanup"])`; initial = `\.storageInitialMode`; Cleanup disabled when `!root.allowsCleanup` with caption "Cleanup is available for your home folder only." (switch back to Space Map on root change). Cleanup content = `CleanupView(compact:)`; `CleanToastHost()` placed once at page level (bottom-trailing overlay of the content area, above both modes; a Space Map trash also produces a toast).
- **Space Map** (`SpaceMapView`): breadcrumb (`body12`, ancestors `textSecondary` + clickable → set focus via repeated `up()` or `drill(ancestor)`, current `textPrimary`, names via `spaceMap.path(of:)` last component, root shown as `~`); treemap card span 2 (`TTSpaceMap` tiles from `children(of: focus)`: `.restricted` when `bytes == nil`, value text via `StorageFormat.bytes(…, .estimate when overlay==nil)`); children table card (Name, Size, %, Items when !compact) built from the **same** `TTSpaceMapLayout.make(tiles, in: mapSize)` set incl. the "N smaller items" row (not drillable). Hover: map binds `hover.hoveredID`; table `hover:` binding maps row id ↔ tileID. Only the hover layer and the two affected rows re-render on hover (don't read `hover.hoveredID` in `SpaceMapView.body`).
- **Menu** (rows via `rowMenu`, tiles via `.contextMenu` on the map targeting the tile under the pointer at right-click = `hover.hoveredID`): Reveal in Finder (`storage.reveal(path:)`) · Move to Trash… (enabled iff `trashItem(for:)` non-nil and policy allows; disabled → `.help(reason)` with copy per `DenyReason`: anchor "Protected system or home folder", protected "Protected data (Mail, Keychains, iCloud…)", outsideRoot "Outside the scanned folder", unverifiable "Can't verify this item"; confirm via `presentConfirmDialog` title `Move “{name}” to Trash?`, message `{size} will be moved to the Trash.`, confirm `Move to Trash` → `storage.clean([item])`; refused (false) → nothing) · Ignore (`storage.ignore(path:)`). Restricted / smaller entries: no menu. If a tile context menu can't target the hovered tile reliably with `TTSpaceMap` as is → conditional ownership of `TTSpaceMap.swift`: add `tileMenu: ((Int32) -> AnyView)?` (default nil), re-record `component-space-map*` only if pixels change.
- **Keyboard** (focusable Space Map container, `.onKeyPress`): ←/→/↑/↓ move `hover.hoveredID` through the size-sorted tile order (and table selection), Return drills the hovered/selected normal tile, ⌘[ and Backspace → `up()`. Table: click selects, **double-click drills** (`onDoubleClick`).
- **States** (`StorageStates`, spec §4.5 / DESIGN §3.17): `.idle` without tree → `TTEmptyState(.empty("Scan your home folder to see what uses space."))` + `Scan` (`.smallPrimary`); `.loadingCache` → header + strip, empty content (no spinner flash); `.scanning(hasPrevious: false)` → progress card (files grouped, bytes §5.3, `currentPath` **middle**-truncated, `Cancel`) above the partial treemap of the root's children; `.scanning(hasPrevious: true)` → previous result + floating progress card; `.failed(.volumeRemoved)` → "Volume was removed"; `.failed(.rootUnreadable(r))`/`.io(r)` → empty state with the reason; `.failed(.cancelled)` without a tree → never-scanned state.
- **Lifetimes**: `.task { applyClassifyOptions-from-settings if changed; await storage.pageDidAppear() }`, `.onDisappear { storage.pageDidDisappear() }`. Never call `Date()` in view bodies except the `\.now ?? Date()` fallback.
